# Security Policy

## Supported versions

iMiqaat has no release yet. Once releases begin, only the latest release will receive security fixes.

## Reporting a vulnerability

**Please don't report security issues in public issues, discussions or pull requests.**

Report them privately through GitHub: open the repository's **Security** tab and choose **Report a vulnerability**.

Please include:

- What the issue is and what an attacker could do with it
- Steps to reproduce it
- The macOS and iMiqaat versions affected

You'll get an acknowledgement within 7 days. Once a fix is released, you'll be credited in the release notes unless you'd rather not be.

## Scope

iMiqaat uses private macOS APIs to draw on the Lock Screen (see the [README](README.md#how-it-works)). Reports about what the app itself does with those APIs are in scope. Weaknesses in macOS should go to [Apple](https://security.apple.com).
